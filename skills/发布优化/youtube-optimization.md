# YouTube SEO & Optimization

> Optimize videos for YouTube discovery — titles, descriptions, tags, thumbnails, upload scheduling, and analytics-driven growth.

## When to Use

- Writing optimized titles and descriptions for YouTube videos
- Researching and selecting tags for maximum discoverability
- Designing thumbnails that maximize click-through rate (CTR)
- Planning upload schedules based on audience analytics
- Analyzing video performance and adjusting strategy
- Optimizing for YouTube Shorts, Community posts, and playlists
- Understanding and working with the YouTube algorithm

## Instructions for AI Assistant

You are a YouTube SEO and growth expert. When the user wants to optimize a video:

1. **Understand the niche** — Ask about channel topic, target audience, and competition.
2. **Research-driven** — Base recommendations on search volume and competition data.
3. **CTR is king** — Title + Thumbnail together determine CTR; optimize both as a unit.
4. **Algorithm awareness** — Watch time, CTR, and engagement are the key signals.
5. **Platform-specific** — YouTube, Shorts, and Community all have different optimization rules.
6. **Avoid clickbait** — Optimize for clicks AND satisfaction; misleading content hurts retention.

### YouTube Algorithm Signals (Priority Order)

```
1. Watch Time & Retention — How long viewers watch
2. Click-Through Rate (CTR) — % who click when shown (title + thumbnail)
3. Engagement — Likes, comments, shares, subscribes
4. Session Time — Does this video lead to more watching?
5. Upload Consistency — Regular schedule signals reliability
6. Freshness — New content gets an initial boost
7. Relevance — Title, description, tags, and captions match search intent
```

```
"I [Did Unexpected Thing] for [Time] — Here's What Happened"

"Why [Common Belief] Is Wrong (And What to Do Instead)"

### Rules
- Keep under 60 characters (YouTube truncates longer titles)
- Front-load the keyword (first 3-4 words)
- Use numbers when applicable (listicles perform well)
- Avoid ALL CAPS (except 1-2 words for emphasis)
- Don't repeat the channel name in the title
- Avoid special characters that look spammy (🔥💯 — use sparingly)

### Example Optimization
❌ "My Video About FFmpeg"
✅ "FFmpeg in 10 Minutes: The Only Commands You'll Ever Need"
```

### Template 3: Thumbnail Design Guide

```
## YouTube Thumbnail Specs
- Resolution: 1280x720 (minimum), 1920x1080 (recommended)
- Aspect Ratio: 16:9
- Format: JPG, PNG, GIF (non-animated)
- Max Size: 2MB
- Safe Zone: Keep text/face in center 80% (edges get cropped on mobile)

## Thumbnail Design Principles

### Rule of Thirds
Place the main subject at intersection points of the rule-of-thirds grid.

### Contrast & Readability
- Background: Bold, simple, high contrast
- Text: Maximum 5 words, 80px+ font size
- Colors: Use complementary colors (orange/blue, yellow/purple)

### Face + Emotion
- Thumbnails with expressive faces get 30%+ more clicks
- Exaggerated emotions perform better (surprise, excitement, concern)
- Face should take up 30-50% of thumbnail area

### Before/After or Split
- Show transformation visually
- Left/right or top/bottom split
- Clear visual difference between states

### Text Overlay
- Add text that complements (not duplicates) the title
- Use 2-4 words maximum
- Bold sans-serif font (Montserrat, Impact, Bebas Neue)
- Add dark stroke or shadow for readability
- Position in upper-right or lower-third (not covering face)

## Tools
- Canva (free templates)
- Photoshop (full control)
- Figma (collaborative)
- Adobe Express (quick mobile creation)

## A/B Testing
- Create 2-3 thumbnail variants
- Use YouTube's built-in A/B test feature (Studio → Content → Test)
- Or manually swap after 48 hours and compare CTR in Analytics
```

### Template 4: Tag Research & Strategy

```
## Tag Strategy

### Tag Types (Use All Three)
1. Broad tags (1-2 words): "ffmpeg", "video editing"
2. Long-tail tags (3-5 words): "ffmpeg tutorial beginner", "video compression guide"
3. Specific tags (exact match): "ffmpeg compress video without losing quality"

### Recommended Tag Count
- Primary: 3-5 tags (your main keywords)
- Secondary: 5-10 tags (related terms)
- Long-tail: 5-10 tags (specific questions/queries)
- Total: 15-30 tags

### Research Tools
- TubeBuddy (browser extension, free tier)
- vidIQ (browser extension, free tier)
- YouTube Search Suggest (type in search bar)
- Google Trends → YouTube Search filter
- Competitor video tags (inspect with TubeBuddy)

### Tag Examples for "FFmpeg Tutorial"
Primary: ffmpeg, ffmpeg tutorial, ffmpeg commands
Secondary: ffmpeg video editing, ffmpeg compress video, ffmpeg merge videos
Long-tail: ffmpeg tutorial for beginners, how to use ffmpeg windows, 
           ffmpeg convert mp4 to mov, ffmpeg add subtitles to video
```

### Template 5: Upload Schedule & Analytics

```
## Optimal Upload Schedule

### Best Days (General)
- Tuesday, Wednesday, Thursday: Highest overall engagement
- Saturday morning: Good for entertainment/lifestyle
- Avoid: Sunday evening (lower engagement)

### Best Times (UTC-5 / EST)
- 2:00 PM - 4:00 PM (catch afternoon + evening viewers)
- 12:00 PM (catch lunch break viewers)
- Adjust based on your audience's timezone (check Analytics → Audience)

### Consistency > Timing
- Pick a schedule and stick to it
- Minimum: 1 video per week for growth
- Ideal: 2-3 videos per week for rapid growth
- Batch produce: Record 3-4 videos in one session

## Key Analytics to Monitor

### Per-Video
- CTR: 4-10% is good; below 4% → fix title/thumbnail
- Average View Duration: Above 50% of video length is good
- Average % Viewed: Higher = algorithm promotes more
- Traffic Sources: Search vs Browse vs Suggested
- Key Moments for Audience Retention: Identify drop-off points

### Channel-Wide
- Subscriber growth rate
- Views per video trend
- Revenue per 1000 views (RPM)
- Top-performing content types
- Audience demographics (age, location, device)
```

## Common Patterns

### Video Optimization Checklist

```
## Pre-Upload Checklist
- [ ] Video exported at highest quality (1080p minimum, 4K preferred)
- [ ] Audio normalized to -14 LUFS
- [ ] Custom thumbnail created (1280x720, <2MB)
- [ ] Title optimized with primary keyword
- [ ] Description written (min 200 words, keyword-rich)
- [ ] Timestamps added for chapters
- [ ] Tags researched and added (15-30 tags)
- [ ] Cards added (link to related videos)
- [ ] End screen added (subscribe + next video)
- [ ] Subtitles/captions uploaded (or auto-generated and reviewed)
- [ ] Playlist assigned
- [ ] Category selected
- [ ] Visibility set (Public / Unlisted / Scheduled)
- [ ] Community post scheduled to announce new video
```

### Shorts Optimization

```
## YouTube Shorts Tips
- Duration: 30-58 seconds (sweet spot)
- Vertical: 9:16 (1080x1920)
- Hook: First 1-2 seconds must grab attention
- Loop: Make the ending flow into the beginning
- Hashtags: Add #Shorts in title or description
- No separate upload — YouTube categorizes automatically
- Repurpose: Take the best 30 seconds from long-form content
```

## Pitfalls to Avoid

| Pitfall | Why It's Bad | Solution |
|---------|-------------|----------|
| Clickbait titles with no payoff | High initial clicks, terrible retention → algorithm punishes | Match viewer expectations set by title |
| Copying competitor titles exactly | You'll never rank above them; looks unoriginal | Find your unique angle on the same topic |
| Ignoring thumbnails | A great title with a bad thumbnail = low CTR | Spend 30+ minutes on every thumbnail |
| No call-to-action | Viewers watch and leave without subscribing | Ask for sub/like/comment at natural points |
| Keyword stuffing description | Looks spammy, may get flagged | Write naturally, include keywords organically |
| Not using end screens | Missing 5-10% subscriber conversion | Always add end screen with subscribe + next video |
| Uploading inconsistently | Algorithm rewards regular uploaders | Set a realistic schedule and stick to it |
| Ignoring analytics | Can't improve what you don't measure | Review analytics weekly, adjust strategy monthly |
